# Iron Dominion: CTF Edition (GUI)

Графическая мини-стратегия для Windows под reverse-engineering таск.

## Что изменилось

- Теперь это **GUI-приложение WinAPI** (окно, кнопки, лог действий, статус ресурсов), а не консоль.
- Кодовая база существенно увеличена: отдельные функции для UI, обработчиков действий, цикла хода и финализации игры.
- Враг имеет фиксированный бонус силы `x2`.
- Мультипликатор игрока спрятан в бинарнике и по умолчанию не даёт выполнить условие победы.
- Для реального захвата столицы нужен множитель игрока `x3+` (задача для реверса/патча).
- После победы показывается флаг: `flag{revers_n0_ez}`.

## Правила для игрока

Цель — захватить столицу врага до 18 хода.

Кнопки:

- `Develop` — развитие (еда/технологии/армия)
- `Recruit` — набор войск за еду
- `Raid` — рейд по врагу
- `Assault` — попытка финального штурма
- `Restart` — перезапуск партии

## Сборка под Windows

### MinGW-w64

```bash
x86_64-w64-mingw32-gcc reverse_strategy_ctf.c -O2 -s -mwindows -o IronDominionCTF.exe
```

### MSVC (Developer Command Prompt)

```bat
cl /O2 /MT reverse_strategy_ctf.c user32.lib gdi32.lib /link /SUBSYSTEM:WINDOWS /OUT:IronDominionCTF.exe
```

## Для организатора CTF

- Раздавайте участникам только `IronDominionCTF.exe`.
- Исходник используйте для верификации и последующего write-up.
- При необходимости усложнения можно добавить упаковщик/обфускацию/anti-debug.
